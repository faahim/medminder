# Medminder - Overview

## Vision
A simple, elegant medication reminder app that helps users never miss a dose.

## Target Users
- Individuals managing daily medications
- Caregivers tracking medications for others
- Anyone with complex medication schedules

## Core Features

### Implemented (Phase 0)
- **Medication Management**: Add, edit, delete medications
- **Flexible Scheduling**: Fixed times, intervals, PRN/as-needed
- **Meal Timing**: Before/after/with meal options
- **Prescription Import**: OCR scan prescriptions via camera
- **Dose Tracking**: Log when doses are taken
- **Today View**: Timeline of upcoming doses
- **History**: View past medication logs

### Planned (Phase 1+)
- **Push Notifications**: Reminders when doses are due
- **Snooze & Skip**: Flexible response to reminders
- **Refill Tracking**: Know when to refill
- **Export/Share**: Share medication list with doctors

## Design Philosophy
- **Clean & Calm**: Light-mode only, minimal visual noise
- **Accessible**: Large touch targets, clear hierarchy
- **Trustworthy**: Medical apps need to feel reliable
