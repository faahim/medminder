## Test Scenarios

### Permission Flow
1. Fresh install → First medication → Onboarding shows → Grant permission
2. Fresh install → First medication → Onboarding shows → Deny → Go to Settings later
3. Fresh install → Skip permission → Add medication → Onboarding shows again

### Basic Reminders
1. Single daily medication → Reminder fires at correct time
2. Multiple daily medications → Each reminder fires at correct time
3. PRN medication → No automatic reminder (unless requested)
4. Medication with end date → Notifications stop after end date
5. Medication with start date → Notifications start on start date

### Interactive Actions
1. Tap "Take Now" → Dose logged, notification dismissed, Today updated
2. Tap "Snooze" → New snooze notification scheduled
3. Tap "Skip" → Dose logged as skipped, notification dismissed
4. Swipe notification → Default behavior (open app)

### Settings
1. Enable/disable global toggle → Notifications stop/start
2. Set quiet hours → No notifications during period
3. Change sound → New sound plays
4. Disable vibration → No vibrate
5. Disable badge → No count on app icon

### Edge Cases
1. App closed for days → Background task reschedules → Notifications still fire
2. Timezone change → All notifications rescheduled correctly
3. Phone offline → Notifications still queue and deliver when online
4. Multiple missed doses → Follow-ups sent for each

### Refill Reminders
1. Set supply 30, daily dose → Reminder at 3/5/7 days (based on setting)
2. Mark as refilled → Counter resets, reminder removed
3. Very low supply (1 day) → Reminder shows in Today view
