## Objective
Make notifications actionable so users can take meds, snooze, or skip directly from the notification shade.

## Acceptance Criteria
- [ ] Take Now button logs dose and dismisses notification
- [ ] Snooze button with options (15/30/60/custom)
- [ ] Skip button logs as skipped with optional reason
- [ ] Action responses are handled correctly when app is in background
- [ ] Action responses update Today view when app returns
- [ ] Haptic feedback when action is taken
- [ ] Notification persists if no action is taken

## Implementation Details

### Notification Categories (already in service)

```typescript
' TAKE': '✓ Take Now',

```

### Response Handler Flow
```typescript
async function handleNotificationResponse(response) {
  const { actionIdentifier, notification } = response;
  const { medicationId, type } = notification.request.content.data;

  switch (actionIdentifier) {
    case 'TAKE':
      await logDose(medicationId, 'taken');
      await Haptics.notificationAsync(Haptics.NotificationFeedbackType.Success);
      break;

    case 'SNOOZE':
      await scheduleSnooze(medicationId, 15); // default 15min
      await Haptics.notificationAsync(Haptics.NotificationFeedbackType.Warning);
      break;

    case 'SKIP':
      await logDose(medicationId, 'skipped');
      await Haptics.notificationAsync(Haptics.NotificationFeedbackType.Error);
      break;

    default:
      // Just opened notification, show medication detail
      router.push(`/medication/${medicationId}`);
  }
}
```
