## Objective
Allow users to customize notifications on a per-medication basis (e.g., disable reminders for PRN meds, change timing).

## Acceptance Criteria
- [ ] Add "Notifications" section to medication detail/edit screens
- [ ] Toggle: enable/disable notifications for this medication
- [ ] Custom reminder time offset (at scheduled time, 5/10/15 min before)
- [ ] Custom sound override per medication
- [ ] Custom snooze duration per medication
- [ ] Settings integrate with global notification service
- [ ] Visual design matches Phase 1 aesthetic

## Implementation Details

### Medication Model Extension
```typescript
interface Medication {
  // ... existing fields
  notificationSettings?: {
    enabled: boolean;          // true by default
    leadTime: 0 | 5 | 10 | 15; // minutes before
    sound?: string;            // override global sound
    snoozeDuration?: number;   // default 15, custom in minutes
  };
}
```
