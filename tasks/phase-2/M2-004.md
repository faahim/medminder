## Objective
Set up background task that ensures notifications are rescheduled if the app has been closed for a while.

## Acceptance Criteria
- [ ] Background task registered with expo-task-manager
- [ ] Task runs daily (e.g., at 2 AM)
- [ ] Task reschedules all active medication notifications
- [ ] Task respects quiet hours settings
- [ ] Task handles errors gracefully (no crashes)
- [ ] Task runs with minimal battery impact

## Implementation Details

### Task Registration
```typescript
import * as TaskManager from 'expo-task-manager';

const BACKGROUND_RESCHEDULE_TASK = 'background-reschedule-notifications';

TaskManager.defineTask(BACKGROUND_RESCHEDULE_TASK, async ({ data, error }) => {
  if (error) {
    console.error('Background task error:', error);
    return;

// Register task
await TaskManager.registerTaskAsync(BACKGROUND_RESCHEDULE_TASK, {
  minimumInterval: 60 * 60 * 24, // 24 hours
  stopOnTerminate: false,
  startOnBoot: true,
});
```

### When to Run
- Daily at low-usage time (e.g., 2 AM)
- Only if notifications are enabled in settings
- Only if user has active medications
