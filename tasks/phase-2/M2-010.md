## Objective
Add refill reminders so users never run out of their medications.

## Acceptance Criteria
- [ ] Track current supply count per medication
- [ ] Calculate days remaining based on dosage schedule
- [ ] Send refill reminder when supply runs low
- [ ] Configurable low-supply threshold (3/5/7 days remaining)
- [ ] Show refill status in Today view when low
- [ ] Quick action to mark as refilled
- [ ] Refill settings in medication detail

## Implementation Details

### Medication Model Extension
```typescript
interface Medication {
  // ... existing fields
  refillSettings?: {
    currentSupply: number;      // e.g., 30 pills
    unit: 'pills' | 'ml' | 'doses';
    lowSupplyThreshold: 3 | 5 | 7 | 10; // days
    lastRefillDate?: string;
  };
}
```

### Days Remaining Calculation
```typescript
function calculateDaysRemaining(med: Medication): number {
  if (!med.refillSettings) return 0;

  const timesPerDay = JSON.parse(med.scheduleTimes).length;
  const days = Math.floor(med.refillSettings.currentSupply / timesPerDay);
  return days;
}
```
