## Objective
Create a premium notification settings screen where users can configure how and when they receive reminders.

## Acceptance Criteria
- [ ] Global notification toggle (on/off)
- [ ] Quiet hours configuration (start/end time)
- [ ] Sound selection (system sounds: default, soft, gentle, none)
- [ ] Vibration toggle
- [ ] Badge count toggle
- [ ] Visual design matches Phase 1 premium aesthetic
- [ ] Settings persist to storage
- [ ] Changes immediately affect notification behavior

### Data Model (Settings)
```typescript
interface NotificationSettings {
  enabled: boolean;
  quietHours: {
    enabled: boolean;
    start: string; // "22:00"
    end: string;   // "07:00"
  };
  sound: 'default' | 'soft' | 'gentle' | 'none';
  vibration: boolean;
  badge: boolean;
  reminderLeadTime: 0 | 5 | 10; // minutes before
}
```
