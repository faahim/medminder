## Objective
Detect when doses are missed and send follow-up reminders to ensure users catch up.

## Acceptance Criteria
- [ ] Detect missed doses (scheduled time passed, no log entry)
- [ ] Send follow-up notification after configurable delay
- [ ] Show "Missed" section in Today view
- [ ] Allow retroactive logging of missed doses
- [ ] Mark missed doses in History view
- [ ] Escalate attention if still missed after follow-up
- [ ] Respect quiet hours (follow-up can be sent outside quiet hours)

## Implementation Details

### Missed Dose Logic
```typescript
function getMissedDoses(today: string, logs: DoseLog[]): DoseLog[] {
  return logs.filter(log => {
    const scheduledTime = new Date(`${today} ${log.scheduledTime}`);
    const now = new Date();
    const hasEntry = logs.some(l =>
      l.medicationId === log.medicationId &&
      l.date === today &&
      l.status !== 'pending'
    );
    return scheduledTime < now && !hasEntry;
  });
}
```

### Follow-up Notification
- First reminder: at scheduled time (normal)
- Follow-up: +2 hours (configurable in settings)
- Escalation: +4 hours (different sound/vibration)
