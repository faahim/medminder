## Objective
Integrate notification service into app lifecycle so notifications are scheduled, managed, and cleaned up reliably.

## Acceptance Criteria
- [x] Request notification permissions on first app launch
- [x] Reschedule all notifications on app startup
- [x] Cancel notifications when medication is deleted
- [x] Update notifications when medication is edited
- [x] Clean up expired medication notifications
- [x] Set up notification action categories (Take/Snooze/Skip)
- [x] Handle timezone changes (reschedule all)
- [x] Update badge count on app foreground

## Implementation Details

### App Startup (_layout.tsx)
```tsx
import { useEffect } from 'react';
import * as Notifications from 'expo-notifications';
import { NotificationService } from '../src/services/notification.service';

export default function RootLayout() {
  useEffect(() => {
    // Request permissions
    NotificationService.requestPermissions();

    // Setup categories
    NotificationService.setupNotificationCategories();

    // Reschedule all notifications
    // (Will load medications from DB and reschedule)

    // Set up notification listener
    const subscription = Notifications.addNotificationResponseReceivedListener(
      handleNotificationResponse
    );

    // Set up timezone change listener
    const timezoneListener = Notifications.addNotificationReceivedListener(
      handleTimezoneChange
    );

    return () => {
      subscription.remove();
      timezoneListener.remove();
    };
  }, []);
}
```

### Notification Response Handler
- Take Now: log dose, close notification, update UI
- Snooze: schedule snooze notification, close
- Skip: log as skipped, close notification
