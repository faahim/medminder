## Objective
Ensure Today view stays in sync with notification state and user actions.

## Acceptance Criteria
- [ ] Today view updates when notification action is taken (Take/Snooze/Skip)
- [ ] Loading state during dose log operation
- [ ] Smooth transition animations when doses change state
- [ ] Pending/Completed sections update correctly
- [ ] Missed section updates when doses become missed
- [ ] Badge count reflects current pending doses

## Implementation Details

### Today View State Flow
```
App Background → Notification Action → Today Update
     ↓                    ↓                    ↓
  Dose logged         Dose status          Refresh doses
                                         ↓
                                  Show updated UI
                                         ↓
                                Update badge count
```

### Response Listener in Context
```typescript
// In TodayContext or useTodaysDoses hook
useEffect(() => {
  const subscription = Notifications.addNotificationResponseReceivedListener(
    async (response) => {
      const { medicationId } = response.notification.request.content.data;

      // Optimistically update UI
      updateDoseStatus(medicationId, 'taken');

      // Then sync with DB
      await syncWithDatabase();
    }
  );

  return () => subscription.remove();
}, []);
```

### Optimistic UI Updates
- Update UI immediately on action
- Show spinner during DB write
- Rollback on error
