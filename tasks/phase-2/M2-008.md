## Objective
Make notification content clear, actionable, and beautiful with proper formatting and emoji.

## Acceptance Criteria
- [ ] Clear title: "Time for [medication name]"
- [ ] Concise body with key details (dosage, timing)
- [ ] Meal timing hint when applicable
- [ ] Medication color indicator in notification icon
- [ ] Emoji usage is tasteful and helpful
- [ ] Sound matches selected setting
- [ ] Vibration matches selected setting

## Implementation Details

### Notification Content Templates

#### Standard Reminder
```
Title: 💊 Time for Aspirin
Body: 100mg · 8:00 AM (take with food)
```

#### PRN Reminder (if applicable)
```
Title: 💊 As Needed: Ibuprofen
Body: 200mg · Take as needed for pain
```

#### Missed Dose Follow-up
```
Title: ⚠️ Missed: Aspirin
Body: You missed your 8:00 AM dose. Tap to log now.
```

#### Snoozed Reminder
```
Title: 💊 Reminder (snoozed)
Body: Aspirin 100mg · Originally 8:00 AM
```

### Notification Icon
- Use medication color as tint
- Medication-type icon (pill, capsule, etc.)
- Large icon format for iOS

### Sound Options
- Default: system notification sound
- Soft: gentle chime
- Gentle: subtle ping
- None: silent (vibration only if enabled)

### Files to Modify
- `src/services/notification.service.ts` - Update notification content templates

## Context
Good notification UX means users know what to do without opening the app.
