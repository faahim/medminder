## Objective
Redesign the Prescription Import flow (camera/upload → OCR → review) to match the new design language.

## Acceptance Criteria
- [x] Import screen with two clear options: Camera, Photo Library
- [x] Camera preview with capture button
- [x] Processing state with animated indicator
- [x] Review screen shows extracted medications in editable cards
- [x] Each extracted medication can be edited or removed
- [x] "Add All" button to import all medications at once
- [x] Error state for failed OCR
- [x] Success state with count of imported medications
- [x] All icons are SF Symbols
