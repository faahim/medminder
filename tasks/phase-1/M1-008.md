## Objective
Redesign the Settings screen with native iOS patterns: grouped sections, native controls, and proper visual hierarchy.

## Acceptance Criteria
- [ ] Grouped sections with headers: Notifications, Appearance, Data, About
- [ ] Native Switch components for toggles
- [ ] Native Picker for selection options
- [ ] Proper chevron indicators for drill-down items
- [ ] Version info at bottom (subtle)
- [ ] Destructive actions (Clear Data) properly styled
- [ ] Icons for each setting row (SF Symbols)
- [ ] Large title navigation header
- [ ] All interactive elements have haptic feedback
- [ ] Proper section spacing and dividers
