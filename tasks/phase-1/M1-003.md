## Objective
Replace the JavaScript-based tab bar with native iOS tabs using NativeTabs from expo-router. This gives us true platform-native feel with proper SF Symbols integration.

## Acceptance Criteria
- [ ] Replace `<Tabs>` with `<NativeTabs>` in `app/(tabs)/_layout.tsx`
- [ ] Use SF Symbols for all tab icons via `<Icon sf="..." />`
- [ ] Proper icon selection: calendar, pills.fill, chart.bar.fill, gearshape.fill
- [ ] Tab bar has proper tint color (#06B6D4)
- [ ] Badge support for pending doses count (Today tab)
- [ ] Haptic feedback on tab switch
- [ ] Remove old TabIcon component and related code
- [ ] Test on iOS simulator (native tabs are iOS-specific)

## Implementation Details

### New Tab Layout
```tsx
import { NativeTabs, Icon, Label } from 'expo-router/unstable-native-tabs';

export default function TabLayout() {
  return (
    <NativeTabs>
      <NativeTabs.Trigger name="index">
        <Icon sf="calendar" />
        <Label>Today</Label>
      </NativeTabs.Trigger>
      <NativeTabs.Trigger name="medications">
        <Icon sf="pills.fill" />
        <Label>Meds</Label>
      </NativeTabs.Trigger>
      <NativeTabs.Trigger name="history">
        <Icon sf="chart.bar.fill" />
        <Label>History</Label>
      </NativeTabs.Trigger>
      <NativeTabs.Trigger name="settings">
        <Icon sf="gearshape.fill" />
        <Label>Settings</Label>
      </NativeTabs.Trigger>
    </NativeTabs>
  );
}
```

### Files to Modify
- `app/(tabs)/_layout.tsx` - Complete rewrite
- `src/constants/layout.ts` - Remove TAB_BAR constants (native handles this)

### Files to Remove
- Any custom tab bar components
