## Objective
Install and configure the new dependencies needed for Editor's Choice level UI: SF Symbols, liquid glass effects, and ensure Reanimated is properly configured.

## Acceptance Criteria
- [ ] Install `expo-symbols` for SF Symbols
- [ ] Install `expo-glass-effect` for liquid glass (if available for SDK 54)
- [ ] Verify `react-native-reanimated` is properly configured
- [ ] Verify `expo-haptics` is working
- [ ] Update babel.config.js if needed for Reanimated
- [ ] Create test component to verify all new deps work
- [ ] Clean build passes (`npx expo export --platform ios`)

## Implementation Details

### Dependencies to Install
```bash
npx expo install expo-symbols
npx expo install expo-glass-effect
# Reanimated should already be installed
```

### Babel Config Check
Ensure reanimated plugin is in babel.config.js:
```javascript
module.exports = function (api) {
  api.cache(true);
  return {
    presets: ['babel-preset-expo'],
    plugins: ['react-native-reanimated/plugin'],
  };
};
```

### Test Component
Create `src/components/__tests__/DepsTest.tsx` to verify:
- SF Symbol renders
- Reanimated animation works
- Haptics trigger

## Context
- expo-symbols provides iOS SF Symbols (with fallback on Android)
- expo-glass-effect provides iOS 15+ blur effects
- These are critical for achieving native iOS look
