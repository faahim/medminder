## Objective
Redesign the Medication Detail and Edit screens to match the new design language and provide comprehensive medication information.

## Acceptance Criteria
- [ ] Detail screen shows complete medication info in organized sections
- [ ] Hero section with medication name, dosage, and status
- [ ] Schedule section with visual representation of times
- [ ] Statistics section (doses taken, adherence rate)
- [ ] Quick actions: Edit, Pause/Resume, Delete
- [ ] Edit screen reuses Add Medication form components
- [ ] Proper loading and error states
- [ ] Confirmation dialog for delete action
- [ ] Smooth navigation transitions
- [ ] All icons are SF Symbols

### Edit Flow
- Opens existing medication in form context
- Same UI as Add flow but with pre-filled values
- "Save Changes" instead of "Add Medication"

### Delete Confirmation
```tsx
Alert.alert(

  [
    { text: 'Cancel', style: 'cancel' },
```
