## Objective
Redesign the Medications list screen to be scannable, searchable, and beautiful. Users should be able to quickly find and manage their medications.

## Acceptance Criteria
- [ ] Native search bar using Stack headerSearchBarOptions
- [ ] Segmented control for filtering: All / Active / Completed
- [ ] Redesigned medication list items with proper visual hierarchy
- [ ] Each item shows: name, dosage, schedule summary, next dose time
- [ ] Quick actions via context menu (long press)
- [ ] Swipe to delete with confirmation
- [ ] Empty state for each filter state
- [ ] "Add Medication" CTA when list is short
- [ ] Smooth list animations when filtering
- [ ] All icons are SF Symbols
- [ ] Uses FlatList with proper item separators

## Implementation Details

### Screen Structure
```tsx
<Stack.Screen
  options={{
    title: 'Medications',
    headerLargeTitle: true,
    headerSearchBarOptions: {
      placeholder: 'Search medications',
      onChangeText: setSearchQuery,
    },
  }}
/>
```

### Segmented Control
```tsx
import SegmentedControl from '@react-native-segmented-control/segmented-control';

<SegmentedControl
  values={['All', 'Active', 'Completed']}
  selectedIndex={filterIndex}
  onChange={(event) => setFilterIndex(event.nativeEvent.selectedSegmentIndex)}
/>
```
