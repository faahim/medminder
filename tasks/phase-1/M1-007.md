## Objective
Redesign the History screen to show medication adherence over time. Users should understand their patterns and feel motivated by their progress.

## Acceptance Criteria
- [x] Horizontal week calendar strip at top (swipeable)
- [x] Selected day shows detailed log below
- [x] Stats cards: Adherence %, Current streak, Best streak
- [x] Weekly adherence chart (simple bar chart)
- [x] Day log shows all doses with timestamps and status
- [x] Color-coded status indicators (taken=green, skipped=gray, missed=red)
- [x] Date picker for jumping to specific date
- [x] Empty state for days with no medications
- [x] Smooth transitions when changing dates
- [x] All icons are SF Symbols
