## Objective
Redesign the multi-step Add Medication wizard to feel smooth, intuitive, and delightful. Each step should be clear and the flow should feel effortless.

## Acceptance Criteria
- [x] Progress indicator at top showing current step
- [x] Smooth slide transitions between steps
- [x] Step 1: Name & Dosage with autocomplete suggestions
- [x] Step 2: Schedule Type (Fixed times, Interval, As Needed)
- [x] Step 3: Time Selection with time inputs
- [x] Step 4: Meal Timing with visual selection
- [x] Step 5: Duration & Refill settings
- [x] Step 6: Confirmation with live preview card
- [x] "Preview" card builds progressively as user fills form
- [x] Keyboard avoiding behavior on all input screens
- [x] Back button confirms if data will be lost
- [x] Success animation on completion
- [x] Icon component supports SF Symbols (expo-symbols on iOS)

## Implementation Details

### Progress Indicator
```
Step 1 of 6
●───○───○───○───○───○
Name    Schedule    Time    Meal    Duration    Confirm
```

### Flow Structure
```
/medication/add        → Step 1: Name & Dosage
/medication/schedule   → Step 2: Schedule Type
/medication/time       → Step 3: Time Selection
/medication/meal       → Step 4: Meal Timing
/medication/duration   → Step 5: Duration
/medication/confirm    → Step 6: Review & Save
```

### Transition Animation
```tsx
// In each step screen
import Animated, { FadeInRight, FadeOutLeft } from 'react-native-reanimated';

<Animated.View entering={FadeInRight} exiting={FadeOutLeft}>
  {/* Step content */}
</Animated.View>
```

### Preview Card (builds as you go)
```tsx
// Shown at bottom of each step
<MedicationPreviewCard
  name={form.name}
  dosage={form.dosage}
  schedule={form.schedule}
  // Only shows what's been filled
/>
```

### Native Controls
- DateTimePicker for time selection
- SegmentedControl for schedule type
- Visual pills/chips for meal timing
