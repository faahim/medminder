## Objective
Create the foundational design system that all UI components and screens will use. This establishes the visual language for the entire app.

## Acceptance Criteria
- [ ] Create `src/design/tokens.ts` with color palette, spacing, typography, shadows
- [ ] Update `tailwind.config.js` to use new design tokens
- [ ] Create `src/design/theme.ts` with theme context (for future dark mode potential)
- [ ] Document the design system in `docs/DESIGN-SYSTEM.md`
- [ ] TypeScript types for all tokens
